IDE 안에서 코드 수정·테스트·PR까지 자율로 수행하는 에이전트가 확장되는 소식을 정리합니다.

## 발표 내용

GitHub Copilot 코딩 에이전트가 JetBrains 계열 IDE에 공개 프리뷰로 등장했다고 합니다. 코드 수정, 테스트 실행, PR 생성까지 자율적으로 수행하며, 기존 VS Code 위주였던 에이전트 기능이 다른 IDE로 넓어지는 흐름입니다.

## 개발자 관점

주목할 실무 포인트는 '전역 자동승인' 설정입니다. 에이전트가 모든 작업을 확인 없이 실행하도록 열어두면, 파일 삭제나 되돌리기 어려운 명령까지 무확인으로 수행될 수 있습니다. 편의와 위험의 트레이드오프라, 특히 도입 초기에는 자동승인을 끄고 각 작업을 검토하며 쓰는 게 안전합니다. 에이전트의 생산성은 매력적이지만, "무엇을 자동으로 허용할지"의 경계를 사람이 통제하는 습관이 중요합니다.
